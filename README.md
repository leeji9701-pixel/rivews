# 101번지 남산돈까스 리뷰 답글 자동화

배달의민족과 쿠팡이츠 각 3개 계정의 미답변 리뷰를 매일 정해진 시간에 처리해요.

| 리뷰 | 처리 |
|---|---|
| 3~5점, 클레임·욕설 없음 | 템플릿 답글 **자동 등록** |
| 1~2점, 또는 클레임·욕설 키워드 포함 | **자동 등록 안 함.** 확인 → 캡처(`악성리뷰/날짜/`) → 답글 초안 작성 → `확인대기.xlsx`에 **검수대기**로 저장. 등록은 담당자가 캡처와 초안을 보고 플랫폼에서 직접 해요 |

자동 답글 템플릿은 아래 순서로 골라요.
1. 3점: **3점** 템플릿 ("다음번에는 꼭 만족하실 수 있는…")
2. 주문 3회 이상: **VIP 단골** 템플릿 ("무려 N번째나…")
3. 사진이 있는 리뷰: **사진 리뷰** 템플릿
4. 그 외: **기본** 템플릿

악성·저별점 답글 초안은 클레임 유형별로 달라요. 유형은 건강이상, 이물질/위생, 조리상태, 누락/배달, 서비스, 환불요청, 불만일반, 기본이에요.

플랫폼이 답글 앞에 `000님,`을 자동으로 붙이기 때문에 템플릿은 본론부터 시작해요.

---

### 두 브랜드를 함께 운영하는 계정 (gaga)

아이디가 `gaga`로 시작하는 계정은 **101번지 남산돈까스**와 **가가솥밥(14928762)** 두 매장을 하나씩 선택해서 각각 답글을 달아요.
- 가가솥밥 리뷰에는 가가솥밥 문구(`config/templates.yaml`의 `brands: gagasotbap`)가 들어가요.
- 매장 선택이 확인되지 않으면 그 매장은 **건너뛰어요.** 다른 매장 리뷰에 다른 브랜드 답글이 달리지 않게 하기 위해서예요.
- 처리내역과 확인대기 엑셀에 **매장** 칸이 추가됐어요.
- 매장이나 브랜드를 추가하려면 `config/settings.yaml`의 `multi_store_accounts`를 고치면 돼요.

## 처음 설치 (사무실 윈도우 PC, 한 번만)

1. [python.org](https://www.python.org/downloads/)에서 Python 3.11 이상을 설치해요. 설치 화면에서 **"Add python.exe to PATH"**를 꼭 체크하세요.
2. 이 폴더를 PC에 내려받아요. 예: `C:\남산돈까스\리뷰자동화`
3. **`1_설치.bat`** 을 더블클릭해요. 필요한 프로그램을 설치하고, 매일 08:30 실행을 작업 스케줄러에 등록해요.
4. 폴더에 생긴 **`.env`** 파일을 메모장으로 열어 6개 계정의 아이디와 비밀번호를 입력해요.
   - 이 파일은 이 PC에만 있고 GitHub에는 올라가지 않아요. 채팅이나 메신저로 보내지 마세요.
5. **`페이지점검.bat`** 으로 실제 리뷰 화면을 저장한 뒤 `config/selectors.yaml`을 맞춰요. 아래 ⚠️ 항목을 참고하세요.
6. **`2_최초로그인.bat`** 을 실행해요. 계정마다 브라우저가 열리면 문자 인증까지 직접 마쳐요. 로그인 상태가 저장되어 이후에는 자동으로 로그인돼요.

> ⚠️ **첫 실행 전 점검 필수:** 배민과 쿠팡이츠 사장님 사이트는 로그인해야 볼 수 있어요. 그래서 화면의 버튼과 리뷰 위치(`config/selectors.yaml`)는 **실제 화면을 보지 않고 넣은 초기값**이에요.
> `페이지점검.bat` 을 실행하면 `data/dump/`에 화면 캡처(.png)와 HTML이 저장돼요. 계정마다 리뷰 화면, 미답변 탭, **답글창을 연 화면**(등록은 하지 않음)을 저장해요. 이 파일로 선택자를 맞추면 돼요. 고객 닉네임이 들어 있으니 외부 공유에 주의하세요.
> 배민 리뷰 화면은 2026-09-29 실제 화면 기준으로 맞춰뒀어요. 답글 입력창과 등록 버튼, 쿠팡이츠 리뷰 화면은 아직 확인이 필요해요.

## 매일 쓰는 방법

| 파일 | 용도 |
|---|---|
| (자동) 매일 08:30 | 로그인 → 미답변 리뷰 분류 → 3~5점 자동 답글 / 악성·저별점 캡처와 초안 작성 |
| `지금실행.bat` | 지금 바로 한 번 실행 |
| `확인대기.xlsx` | 악성·저별점 리뷰 목록과 **답글 초안**. 캡처를 보고 초안을 다듬어 플랫폼에 직접 등록한 뒤, 상태를 `등록완료`로 바꿔요 (목록에서 선택) |
| `악성리뷰/2026-09-28/` | 확인이 필요한 리뷰 캡처 이미지 |
| `처리내역/2026-09-28.xlsx` | 그날 처리한 리뷰와 답글 전체 기록 |
| `logs/` | 실행 로그 (오류가 나면 여기부터 확인) |

### 시험 운영 → 실제 운영

처음에는 `config/settings.yaml`의 `dry_run: true` 상태예요. 템플릿 답글을 **등록하지 않고** `처리내역` 엑셀에 초안만 남겨요.
1~2주 동안 초안이 제대로 나오는지 확인한 뒤 `dry_run: false`로 바꾸면 실제 등록이 시작돼요.
악성·저별점 리뷰는 이 설정과 관계없이 **절대 자동 등록하지 않아요.**

## 실행 시간 바꾸기 (연차·반차)

| 파일 | 용도 |
|---|---|
| `매일시간변경.bat` | 매일 실행 시간을 바꿔요. 예: `09:00` |
| `연차반차_시간변경.bat` | **특정 날짜만** 다른 시간에 실행해요. 예: 오후 반차면 날짜 입력 후 `13:30`. 하루 종일 쉬려면 `쉼` 입력 |
| `연차반차_취소.bat` | 날짜별 예외를 취소해요 |

- 날짜별 예외를 설정하면 그날 08:30 정기 실행은 건너뛰고, 지정한 시간에만 실행돼요.
- `쉼`으로 설정한 날의 리뷰는 다음 실행 때 한꺼번에 처리돼요.
- 정해진 시간에 PC가 꺼져 있었다면, 켜진 뒤 바로 실행돼요.

## 템플릿·규칙 수정

`config/templates.yaml`을 메모장으로 열어 고쳐요.
- `positive`: 3~5점 템플릿 문구. `{order_count}` 자리에 주문 횟수가 들어가요.
- `claim_categories`: 클레임 유형별 키워드와 답글 초안. 위에 있는 유형이 우선이에요.
- `manual_default_reply`: 키워드 없는 1~2점 리뷰나 욕설만 있는 리뷰에 쓰는 기본 초안
- `vip_min_orders`: 단골 템플릿을 쓸 최소 주문 횟수 (기본 3)
- `manual_max_rating`: 이 별점 이하는 확인 후 등록 (기본 2)
- `abusive_keywords`: 확인 후 등록으로 보낼 욕설·비방 단어

## 주의사항

- PC가 켜져 있고 **윈도우에 로그인된 상태**여야 실행돼요. 브라우저 창이 떴다가 작업이 끝나면 닫혀요.
- 플랫폼이 화면을 바꾸면 `config/selectors.yaml`을 다시 맞춰야 해요.
- 너무 빠른 반복 작업은 계정 제한 위험이 있어서, 동작 사이에 2~5초씩 쉬도록 설정되어 있어요.
- 플랫폼 이용약관에서 자동화 도구 사용이 허용되는지 확인한 뒤 운영하세요.

## 개발자용

```bash
pip install -r requirements.txt pytest
python -m pytest            # 분류·템플릿·가짜 리뷰 페이지 흐름 테스트
python -m review_bot --help
```

구조: `review_bot/classifier.py` (분류), `templates.py` (템플릿 선택), `site.py` (플랫폼 화면 조작, selectors.yaml 기반), `runner.py` (전체 흐름), `sheets.py` (엑셀), `schedule.py` (작업 스케줄러)
